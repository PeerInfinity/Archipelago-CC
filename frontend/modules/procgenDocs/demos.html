How to run any of these

Every entry carries two links. open it here is the entry on the host this page is being served from — a dev server rooted at the repo, or the deployed site. on Pages is always the same run on GitHub Pages, deployed from main by .github/workflows/deploy-gh-pages.yml, which publishes the frontend/ directory as the site root — so /frontend/modules/… in the repo is /Archipelago-CC/modules/… there.

To serve it yourself:

python -m http.server 8000          # only if one is not already up on :8000

⚠ Pages serves the tree as of the last push to main, so a demo that reads a claim off a page changed locally but not yet pushed will show the older behaviour there.

Every URL below is the spelling the page's OWN writer produces (watchGenerate.writeGenerateParams / mazeLab.writeLabParams), so pasting one back into the bar is a fixed point — the page reloads exactly the run the link names. ⛔ None of them was typed by hand, and neither link is: both are computed from the entry by the two helpers in demos.js. Because that is a claim about a STRING, every entry keeps both of them readable and copyable: press copy for the one you would paste, or open the URLs, in full to read them character by character.

Two controls appear in nearly every entry and are worth learning once:

— the PHASE ladder (◀ PHASE / the slider / PHASE ▶ / the FINISHED level) walks the GENERATION, one phase at a time. Phase k is the room as of ledger row k, rebuilt from the row deltas — ⛔ nothing is re-run, and the readout under it carries that phase's own sentence, its tile/entity delta and its refusal by name.

— the FACT LINES under the phase readout are the phase's INTERMEDIATE RESULTS — every candidate set, flood, region and pick it computed. ⚖ Ticking a line draws it (the user's ruling of 2026-08-18: "only display the visual representation when the corresponding text description is selected"). The overlay select beside them is a separate, cumulative picture of the finished level (off → sites → elements → areas → all).

⛔ Neither is a URL parameter. They are VIEW settings: they re-draw, they never regenerate. A link names a RUN.

How to read an entry

⛓ This page is a RENDERER, not the catalogue. The catalogue is frontend/modules/procgenDocs/demos.js — a frozen array of entries — and this page and scripts/procgen/check-procgen-demos.mjs are its two readers. The row IMPORTS the same module, LOADS every link shown here and asserts each entry's own claim off the page's readout, so an entry whose seed stops behaving the way the prose says goes RED rather than rotting quietly. Phase, Facts and Layer are DRIVEN by that row when present — it presses the slider, ticks the boxes and sets the select before it asserts. Everything else is for you.

node scripts/procgen/check-procgen-demos.mjs                 # the whole catalogue
node scripts/procgen/check-procgen-demos.mjs --only=sword-gated
node scripts/procgen/check-procgen-demos.mjs --pages=https://peerinfinity.github.io/Archipelago-CC

⛔ A catalogue entry without a claim is not an entry, and the row fails on one. Adding or regenerating an entry is documented in docs/json/developer/procgen/demos.md — ⛔ never hand-spell a URL.
