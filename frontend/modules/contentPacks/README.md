# contentPacks

**Content packs: data directories under `frontend/packs/<id>/` that can be stacked.** This module finds them,
loads several at once, and merges them in a defined order. It is shared by the art library now
(`../artLibrary/`), and it is shaped for the concept library to use later.

- `contentPacks.js`:
  - `parseRegistry` reads `frontend/packs/packs.json`: the packs, plus the named **stacks** under `graphics`.
  - `loadPackStack(ids, { base, readJson })` loads each pack's `pack.json` and its layers, in order.
  - `mergeKeyed` merges one keyed table across the stack.
  - `packsBaseUrl` returns `../../packs/` unbundled and the page's `packs/` in a bundle.
- **Override order:** a later pack in the stack wins per key. A reskin stacked last replaces only the keys it
  carries; everything else falls through to the packs before it.
- **Keys are namespaced:** `seedling:tile/ground`, `archipelago:pickup/item`. Every library uses the same key
  for the same thing, so a concept entry can later name its art key.
- ⛔ **Refusal by name:** a malformed pack is never half-loaded. Each of these throws a `ContentPackError`
  that names the pack and the field:
  - a wrong `id` for its directory;
  - an unknown schema version;
  - a missing licence;
  - a layer this loader does not know;
  - a path that leaves the pack;
  - an un-namespaced key.
- **Layers:** `KNOWN_LAYERS` is `['art']` today. There is room for `concepts/` and maze `rules/` later; a new
  consumer adds its layer name there.
- DOM-free: the caller supplies `readJson`. Node tests read the committed packs from disk.

The packs:

| Pack | How it is made |
|---|---|
| `seedling` | Generated by `scripts/procgen/extract-seedling-art-packs.mjs` (`--check` gates drift in `scripts/procgen/seedlingSource.test.js`). |
| `archipelago` | Generated by the same script. |
| Any other (e.g. a reskin) | Hand-made: add its directory and a row in `packs.json`. |
