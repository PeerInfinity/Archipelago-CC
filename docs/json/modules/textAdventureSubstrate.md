# Text Adventure (Substrate)

Substrate-style replacement for the existing
[Text Adventure](textAdventure.md) module. Renders procgen-emitted
regions whose substrate is `text_adventure` as textual descriptions
with clickable exits and locations. The existing `textAdventure/`
module continues to handle non-procgen rules.json playback; the two
modules coexist.
