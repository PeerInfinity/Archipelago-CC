# Progress Bar Panel

The Progress Bar panel is a container for progress bars created by other modules (typically the [MetaGame](metaGamePanel.md) system).

> ⚠ **Deprecated** (2026-10-11). The Meta Game and Progress Bars panels and their MetaGame / ProgressBar modules are kept in the code but disabled in every launch mode, and are no longer maintained. See [Deprecated Panels](../../modules/README.md#deprecated-panels).

## Controls

- **Create Test Progress Bar** — Generates a 3-second demo progress bar, useful for verifying the panel works.
- **Clear All** — Removes all progress bars from the panel.

When the MetaGame module is driving progress bars, it typically hides the panel's header and buttons for a cleaner display, leaving only the progress bars themselves visible.
