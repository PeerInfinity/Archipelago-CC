# Start Here

Four short introductions, one for each kind of reader. Each one says what this project offers you and which documents to read next.

- **[Introduction to Archipelago](./introduction-to-archipelago.md)** — new to Archipelago and randomizers? Start here; the rest of the documentation assumes these basics.
- **[For Players](./for-players.md)** — play generated worlds in the browser, watch a bot play them, or track an ordinary Archipelago game.
- **[For World Builders](./for-world-builders.md)** — generate new worlds with the procgen pipeline, package them for Archipelago, or turn a graph or a proof into a world.
- **[For Developers](./for-developers.md)** — set up the repository, find your way around the code, and run the tests.
