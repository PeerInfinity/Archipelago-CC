# Castlevania - Circle of the Moon WorldGen Setup Guide

## Required Software

- Archipelago client

## Installation

1. Download the game's .apworld file
2. Place it in your Archipelago/lib/worlds folder
3. Generate a multiworld with Castlevania - Circle of the Moon WorldGen

## Joining a Game

1. Open the Archipelago client
2. Connect to the server
3. Start playing!
