# Hero Core Randomizer Setup Guide

## Required software

- The Hero Core randomizer build: the `HeroCoreRandomizer*.zip` asset of a
  [HeroCore-Archipelago release](https://github.com/Minish-Link/HeroCore-Archipelago/releases).
- The original game, for its music: [remargames.se](https://www.remargames.se/daniel/herocore.php). The randomizer
  does not ship the music; copy the original's music files into the randomizer's `music` folder.

## Connecting

1. Edit `ConnectionInfo.ini` in the randomizer folder: set `Address` to the server address and port, `SlotName` to
   your slot name, and `Password` if the room has one.
2. Start `herocore.exe` and choose **Connect** on the main menu.

The randomizer does not yet show every message from the server. A text client, or the Universal Tracker (this
world ships tracker maps for each difficulty), shows what you send and receive.
