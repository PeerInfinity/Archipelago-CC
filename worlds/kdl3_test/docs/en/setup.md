# Kirby's Dream Land 3 Test Setup Guide

## Required Software

- Archipelago client

## Installation

1. Download the game's .apworld file
2. Place it in your Archipelago/lib/worlds folder
3. Generate a multiworld with Kirby's Dream Land 3 Test

## Joining a Game

1. Open the Archipelago client
2. Connect to the server
3. Start playing!
