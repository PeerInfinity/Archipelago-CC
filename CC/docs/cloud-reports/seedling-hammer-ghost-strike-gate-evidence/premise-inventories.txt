## Conclusion
No AP-delivered inventory (randomized or ER) puts hasGhostSword up without hasSword. A Ghost-Sword-only run exists only where
the flag is written directly: a staging's `seam.items` / `arrivalStaging(items)`, Bot.as `grantItem` (a probe), the cheat path
(`Game.cheats` grants both), or a vanilla sequence break that takes the GhostSword pickup (Pickups/GhostSword.as: no Sword test)
before the Sword.
