# Profiled structure-departure batch — Pass-B trigger measurement (post-v1 Phase A)

Acceptance batch for the `profiled` structure policy (post-v1 design
§2.2/§2.3). Four departure configs × two seeds, each generated by
`generateJtaDataset` and run through the full roundtrip (world_generator +
Generate.py fill, seed 1) + Pass-B solve, exactly as the Phase 5e mirror
rounds. Reproduce with:

```
source .venv/bin/activate
node CC/scripts/jta-stats/sweep-dataset-passb.mjs --structure '<spec>' --seeds 1,2 --zones 15
```

Configs (the `<spec>` for each):

| config | structure spec | departure axis (§2.2) |
|---|---|---|
| control | `{"policy":"profiled"}` | none — profiled reproduces the mirror structure (id stride aside); the batch's own baseline |
| dense | `{"policy":"profiled","tasksPerZone":{"mean":12,"jitter":0.2}}` | task count ↑ (free-pool clones) |
| sparse | `{"policy":"profiled","tasksPerZone":{"mean":7,"jitter":0}}` | task count ↓ (free-pool drop) → C4 repair |
| skillcount | `{"policy":"profiled","skillCount":13}` | skill roster +3 → C4 repair |

## Generated worlds (all C4-clean after repair)

| world | tasks | skills | C4 repairs |
|---|---|---|---|
| control s1/s2 | 130 / 130 | 10 | 0 / 0 |
| dense s1/s2 | 183 / 177 | 10 | 0 / 0 |
| sparse s1/s2 | 105 / 105 | 10 | 60 / 60 |
| skillcount s1/s2 | 130 / 130 | 13 | 13 / 13 |

Adding tasks (dense) only raises opportunity, so it needs no repair; reducing
tasks (sparse) and introducing skills (skillcount) pull demanded skills below
the profile floor — the mirror sits at exactly 1.00× margin — and the C4
repair loop lifts earlier training back over the floor (every edit ≤ the
profile p95 caps, logged to `provenance.c4_repairs`).

**xp_mult co-solve trigger (§2.5 lever 1) — NOT FIRED.** The trigger is the
estimator inversion running out of cost range with a level deficit: a
milestone whose cost is pinned at the FLOOR (or saturated at the cap) yet
still stalls. **Zero floor-/saturation-clamped milestone stalls across all
eight worlds.** Every milestone stall that does occur is `clamp = threshold`
or `clamp = none` — the known conservative-bar / threshold-drift mode
(§5e result 1, §5f task-256/z12 class): the walk's `other` LEVEL metric
refuses a task the confined frontier can't wait out. §5f established that mode
is emergently completable; the emergent progression gate below is its arbiter,
not the conservative walk bar.

> The `sweep-dataset-passb.mjs` trigger heuristic previously fired on ANY
> milestone stall and would have reported "FIRED" here. It has been tightened
> to §2.5's precise floor-/saturation-clamp condition, and now reports the
> threshold/none milestone stalls separately as conservative-bar stalls.

**economy scaling / starvation triggers — NOT FIRED.** No zone band pinned at
min cost, no saturated band, on any world.

The over-conservative walk bar "fails" (2–12 stalled entries) exactly as it
does on vanilla seed 4 (5 stalled) which plays to full coverage — it is
in-sample and not the acceptance gate. sparse is the hardest for the walk
(gap max 369–424) because its thinned free pool leaves the frontier little to
interleave, but its stalls are still all threshold/none, not level deficits.

**Conclusion (confirms ruling 2 on GENERATED profiled worlds, not just the
§2.4 hand-edits): the C4 repair loop keeps profiled worlds C4-clean, and no
C4-clean world fires the true xp_mult co-solve trigger. The lever stays
UNBUILT.**

Non-gating observations, all previously characterized:
- **Filler stranding** (dense 5, skillcount 2) is the task-256/z12 `other`-LEVEL-metric

  reaches a zone at a different level trajectory than the vanilla anchor, which
  is not a reachability defect (no skill is ever demanded at level 0).

## Verdict

The `profiled` policy + C4 repair loop produces C4-clean worlds across the
task-count (±), skill-count, and (via typeMix, separately guarded) type-mix
departures; none fires the true xp_mult co-solve or economy triggers, and all
pass the emergent progression gate. **Phase A acceptance met; the xp_mult
co-solve lever stays UNBUILT** per ruling 2 (trigger-gated, and no C4-clean
world fires the trigger).
