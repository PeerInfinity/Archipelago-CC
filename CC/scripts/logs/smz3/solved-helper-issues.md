# SMZ3 Solved Helper Issues

## Helpers Implemented

1. **ALTTP helpers** - CanLiftLight, CanLiftHeavy, CanLightTorches, CanMeltFreezors, CanExtendMagic, CanKillManyEnemies, CanBeatBoss
2. **Super Metroid helpers** - CanIbj, CanFly, CanUsePowerBombs, CanPassBombPassages, CanDestroyBombWalls, CanSpringBallJump, CanHellRun, HasEnergyReserves, CanOpenRedDoors
3. **Portal access helpers** - CanAccessDeathMountainPortal, CanAccessDarkWorldPortal, CanAccessMiseryMirePortal, CanAccessNorfairUpperPortal, CanAccessNorfairLowerPortal, CanAccessMaridiaPortal
4. **Region-specific helpers** - CanExit (for Norfair Lower East), CanAccessCrocomire, CanEnterAndLeaveGauntlet, CanUnlockShip
5. **Reward/Dungeon helpers** - CanAcquire (checks if player can complete dungeons to get rewards), GetLocation (checks items at locations)
